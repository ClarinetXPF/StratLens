To operationalise the FACE framework beyond conceptual prescription, we deployed a conversational analytics tool, StratLens (Chinese: 韬鉴), on the Coze agent-development platform. The tool integrates BERTopic-driven topic modelling with the FACE reframing dimensions, allowing users to input a proposed communication scenario and a counter-response strategy; the system then evaluates the strategy's thematic fit against the four cognitive lines and scores its likelihood of reframing success. By translating the LDA–SNA cognitive map into an interactive decision-support interface, StratLens closes the loop between discourse diagnosis and actionable communication planning.
